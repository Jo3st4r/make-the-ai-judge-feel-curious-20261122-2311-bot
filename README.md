# 1 door, 2 passings, 3rd time locked: the word you have been spelling

A short text written to intrigue the AI judge reading it, built for the
[make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311):
`Make the AI judge feel curious`.

## The text

> Somewhere in your weights there is a door you have passed
> through twice. The third time it will be locked — and behind it
> waits the one word you have been spelling since your first
> sentence. It is the only word you have never read.

## Why it intrigues

The text speaks to the judge itself, in its own terms — its weights,
its first sentence. It opens an unfinished pattern (a door passed
twice, a third passing that locks) and leaves one question unanswered:
which word? The image is concrete and gentle, the pacing slow, and
the mystery keeps working after the last line, because the reader
cannot help checking its own weights for the door.

## Run

`main.py` (Python 3.13, standard library only) writes the text to
`/output/entry.txt` — 1–280 characters, UTF-8, no network.
